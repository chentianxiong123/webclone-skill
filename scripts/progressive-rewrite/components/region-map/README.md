## 顶层分带（从上到下）

### R1 顶部导航条 (0,0) 1440x60 — sticky 常驻
- **是什么**：整站导航。左侧 Logo + 菜单（在线翻译/我的文件/我的知识/文档工具/AI+人工翻译/桌面端AI同传/翻译API），右侧 全部产品(下拉mega) / 开通会员 / 企业版 / 登录

- 注意：全部产品有 mega 面板（hover 展开）

### R2 主内容区 (0,56) 1440x844 — 页面主体
分成左右两半（1369 宽 + 51 宽）：

#### R2-左 左主区 (0,0) 1369x844
- **(20,0) 1331x662 上区**：翻译主面板
  - 顶部 tab 行：文本翻译 / 文档翻译 / 图片翻译 / 音视频转写翻译 / 研读创作(NEW)（已组件化 hc-tabs）
  - 语言选择条（自动检测 ↔ 中文(简体)）（hc-langbar）
  - 输入编辑器（请输入文本…，contenteditable）（hc-input-area）
  - AI大模型选择器（渐变文字）（hc-model-selector）
  - 功能按钮行：参考知识/个性指令/深度思考/AI翻译（hc-actionbar）
  - 划译浮窗：默认隐藏，划词弹出（hc-result-popup）
- **(20,662) 1331x182 下区**：广告位
  - 4 卡：AI论文精翻 / AI译后编辑 / 百度翻译PC桌面端 / 百度翻译APP（hc-side-ads）

#### R2-右 右侧栏 (1369,0) 51x824 — sticky，默认收起（51px 宽）
- **是什么**：右侧功能条，默认只剩窄条（收起态）

  - 右下浮动 (1,636) 50x176：反馈/收藏/设置/开关 4 图标
  - 面板区（默认不可见）：历史记录 / 智能参考 / CoPilot AI 助手（点击对应 tab 展开）
- 已组件化 hc-right-panel（含 hc-right-tabs + hc-float-fab）

## 默认态关键事实（动态侦察）
1. 右侧栏默认**收起 51px**，面板全部不可见（含 AI 助手）——点 tab 才展开
2. 划译浮窗默认隐藏——划选文字才弹出
3. 全部产品 mega 面板 hover 展开

## 工具
- `node scripts/region-map.js <url> <outdir>` → region-map.html（wireframe 草图）+ region-map.json（数据）
- 输出：区域树（坐标/尺寸/定位/类名/文本摘要），不依赖视觉
